A tiny Node program that answers the coffee-or-tea question with exactly one letter: A, for coffee. It writes that single letter to the output file and nothing else, then reads it back to prove the entry is exactly one character.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
